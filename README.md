
# Kubernetes Engineering Lab

A hands-on repository documenting my journey of learning Kubernetes, container orchestration, deployment strategies, configuration management, scaling, storage, and cloud-managed Kubernetes.

## Goals

- Understand Kubernetes architecture and internal components.
- Deploy and manage containerized applications.
- Work with Pods, Deployments, Services, and ConfigMaps.
- Understand resource requests, limits, and autoscaling.
- Learn persistent storage and volume management.
- Explore managed Kubernetes services: GKE, EKS, and AKS.
- Practice troubleshooting real-world deployment issues.

## Tech Stack

- Docker
- Kubernetes
- kubectl
- kind
- YAML
- Google Kubernetes Engine (GKE)
- Amazon Elastic Kubernetes Service (EKS)
- Azure Kubernetes Service (AKS)

## Learning Approach

Each topic includes:

1. Concept and architecture
2. YAML manifests
3. Hands-on experiments
4. Observations and explanations
5. Common failure scenarios
6. Troubleshooting commands
